커스터마이즈 select 스크린 리더 실측

0. 기본 select(대조군)

appearance를 바꾸지 않은 평소 select입니다.

1. 글자만

appearance: base-select만 켠 select입니다.

2. 아이콘 + 글자

아이콘은 장식이라 alt를 비웠습니다.

3. 아이콘만(img alt로 이름)

글자 없이 색 동그라미만 보이고, 이름은 이미지의 alt에 있습니다.

4. 아이콘만(option의 label 속성으로 이름)

이미지 alt는 비우고, option의 label 속성에 이름을 넣었습니다.

5. 아이콘만(이름 없음, 잘못된 예)

이미지 alt도, label도 없습니다. WebKit 글이 말하는 황금률을 어긴 경우입니다.

6. 비활성 옵션

품절 색상 두 개를 disabled로 막았습니다.

7. optgroup

밝은 색과 어두운 색으로 묶었습니다.

8. selectedcontent(고른 옵션을 버튼에 복제)

select 안의 button에 selectedcontent를 넣어, 고른 옵션의 아이콘과 글자를 버튼에 그대로 보여 줍니다.

9. 아이콘 + 화면에서만 숨긴 글자

보이는 건 색 동그라미뿐이지만, 옵션 안에 .sr-only 글자를 넣었습니다.
