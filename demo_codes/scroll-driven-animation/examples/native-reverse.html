Native CSS - Reverse

Using animation-direction: reverse to play animations backward relative to scroll.
(animation-direction: reverse로 스크롤 기준 역방향 애니메이션 재생.)

animation-direction: reverse

⚠️ CSS Scroll-Timeline Limitation

CSS scroll-driven animation cannot detect scroll direction. The animation-direction: reverse property reverses the animation playback relative to scroll position, but it does NOT trigger animations only when scrolling up.

CSS scroll-driven animation은 스크롤 방향을 감지할 수 없습니다. animation-direction: reverse는 스크롤 위치에 따라 애니메이션을 역방향으로 재생하지만, "위로 스크롤할 때만" 애니메이션을 트리거하는 것은 불가능합니다.

To detect scroll direction (up/down) and trigger animations accordingly, you need JavaScript. See the alternatives below:
스크롤 방향(위/아래)을 감지하여 애니메이션을 트리거하려면 JavaScript가 필요합니다. 아래 대안을 참고하세요:

→ IO + Direction (JavaScript) → rAF + Direction (JavaScript)

Reverse Playback

Animation plays backward as scroll position increases.
(스크롤 위치가 증가하면 애니메이션이 역방향 재생.)

Scroll Down

Watch the animation play in reverse.
(애니메이션이 역방향으로 재생되는 것을 확인하세요.)

How It Works

animation-direction: reverse plays keyframes from 100% to 0%.
(animation-direction: reverse는 키프레임을 100%에서 0%로 재생합니다.)

🔄

Reversed Keyframes

Animation starts at "to" state and ends at "from" state.
(애니메이션이 "to" 상태에서 시작해 "from" 상태로 끝남.)

📍

Position Based

Still tied to scroll position, not direction.
(여전히 스크롤 위치에 연결, 방향이 아님.)

🎬

Visual Difference

Elements start visible and fade out as you scroll down.
(요소가 보이는 상태로 시작하고 스크롤 시 사라짐.)

What CSS Can Do

  • Map animation progress to scroll position
  • Reverse keyframe playback order
  • Define scroll ranges with animation-range
  • GPU-accelerated smooth animations

What CSS Cannot Do

  • Detect if user is scrolling up or down
  • Trigger animations only on specific direction
  • Remember previous scroll position
  • Conditional logic based on direction

JavaScript Solutions

  • Track lastScrollY for direction
  • Add class like .scroll-up to body
  • Use IO + direction for efficient detection
  • See IO Reverse or rAF Reverse
