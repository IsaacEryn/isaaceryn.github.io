1. popover — 모달이 아니다

Baseline 새로 사용 가능 (2025-01)

팝오버가 열려도 포커스는 갇히지 않습니다. 배경도 그대로 살아 있고요. 툴팁·드롭다운에는 맞는 동작이지만, 반드시 처리해야 하는 UI에 쓰면 문제가 됩니다.

3. dialog — 브라우저가 일을 덜어준다

Baseline 널리 사용 가능 (2024-09)

showModal()로 열면 포커스 트랩·Esc 닫기·배경 비활성화를 브라우저가 해줍니다. 닫을 때 포커스를 되돌리는 것까지요. 문제는 돌아갈 버튼이 사라졌을 때뿐입니다.

열고 Tab을 돌려본 뒤 Esc로 닫아보세요 — 포커스가 어디로 가는지 보세요
대화상자를 닫으면 포커스가 어디로 돌아갔는지 여기에 표시됩니다.
⚠️ 열었던 버튼이 사라지는 경우 — 이때만 손이 필요합니다
삭제를 확정하면 이 버튼이 사라집니다. 그때 포커스가 어디로 떨어지는지 확인해보세요.

삭제하시겠어요?

이 작업은 되돌릴 수 없습니다. Tab을 눌러보세요 — 이 상자 안에서만 돕니다.

정말 삭제할까요?

확정하면 방금 누른 버튼이 화면에서 사라집니다. 브라우저가 포커스를 되돌리려 해도 갈 곳이 없어지는 상황이에요.
